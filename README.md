# Timer Fokus

Aplikasi timer desktop sederhana. File `.exe` untuk Windows dibuat otomatis
oleh GitHub Actions setiap kali file di-push ke repo ini.

## Cara ambil file .exe

1. Buka tab **Actions** di bagian atas halaman repo ini.
2. Klik proses build yang paling atas (biasanya bernama "Build Windows EXE").
3. Tunggu sampai selesai (tanda centang hijau).
4. Scroll ke bawah ke bagian **Artifacts**, klik **TimerFokus-windows** untuk
   mengunduhnya (berbentuk file .zip).
5. Ekstrak file zip tersebut — di dalamnya ada `TimerFokus.exe`, tinggal
   dobel klik untuk menjalankan.
